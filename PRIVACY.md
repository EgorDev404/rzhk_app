# Политика конфиденциальности приложения «Расписание»

Дата вступления в силу: 24 октября 2026 г., 15:00

Приложение «Расписание» (далее — «Приложение») показывает расписание занятий и замены уроков Рязанского железнодорожного колледжа. Приложение является неофициальным и не принадлежит колледжу. Связь с разработчиком: khlustovegor123@gmail.com.

## 1. Какие данные использует Приложение

Приложение не требует регистрации и не собирает ваши имя, телефон, адрес электронной почты, геолокацию, контакты, фото и другие личные данные.

На устройстве хранятся только настройки Приложения (период проверки сайта, тема оформления, выбранная дата) и ранее загруженные файлы расписания (кеш). Эти данные остаются на вашем телефоне и разработчику не передаются.

## 2. Откуда берётся расписание

Приложение загружает файлы расписания и замен с публичного сайта колледжа: https://rzn-jd62.gosuslugi.ru/grafik-zanyatiy/. Сайт колледжа, как любой сайт, может видеть технические данные запроса (например, IP-адрес и тип устройства). Это происходит по правилам самого сайта, разработчик Приложения этими данными не управляет.

## 3. Уведомления

Приложение может сообщать о новом или изменившемся расписании. Для этого используется разрешение на показ уведомлений и, по вашему желанию, разрешение на работу в фоне без ограничений батареи. Отключить уведомления можно в настройках Приложения или Android.

## 4. Сторонние сервисы

Для доставки push-уведомлений Приложение использует сервисы Google (Firebase Cloud Messaging). При этом Google может обрабатывать технические данные устройства: идентификатор установки (токен для доставки уведомлений), IP-адрес, модель устройства и версию Android. Разработчик не использует эти данные для идентификации пользователей и не связывает их с вашей личностью. Подробнее об обработке данных Google: https://policies.google.com/privacy и https://firebase.google.com/support/privacy.

Реклама и сторонняя аналитика в Приложении отсутствуют.

## 5. Передача данных третьим лицам

Разработчик не продаёт и не передаёт ваши данные третьим лицам. Исключение — технические данные, которые обрабатывает Google для доставки push-уведомлений (раздел 4).

## 6. Дети

Приложение предназначено для студентов и преподавателей и не собирает личные данные, в том числе у несовершеннолетних.

## 7. Удаление данных

Чтобы удалить все данные Приложения с устройства, удалите Приложение или очистите его хранилище в настройках Android («Хранилище и кеш» → «Очистить»).

## 8. Изменения политики

Разработчик может обновлять эту политику. Актуальная версия публикуется на этой же странице, дата вступления в силу указана в начале.
