# Расписание — приложение для Android

Показывает расписание колледжа на **сегодня** и **завтра** (и на любой другой день), в оформлении Material You.
Сайт колледжа открывается прямо с телефона — поэтому прокси и серверы не нужны (достаточно российского IP, т.е. без VPN).

## Что умеет
- Вкладки «Сегодня / Завтра» со свайпом, у каждой — отметка «есть / нет / ошибка».
- Красивая загрузка: мерцающий скелет + этапы («Подключаюсь… → Ищу файл… → Готовлю картинку…»).
- Кэш на диске: при открытии расписание появляется мгновенно, свежая версия подгружается тихо.
- Потяните вниз — файл скачивается заново (даже если имя то же), картинка обновляется, если содержимое изменилось.
- Если расписания ещё нет — аккуратное пустое состояние и кнопка «Сообщить, когда выложат».
- Нестандартные имена файлов (`Chetverg_01.10_1.pdf`, версии `_1`…`_3`) и поиск по ссылкам на страницах сайта.
- Полноэкранный просмотр: щипок и двойной тап для увеличения, свайп между страницами.
- Уведомления: фоновая проверка каждые 15/30/60 минут (WorkManager), без сервера.
- Динамические цвета из обоев (Android 12+), светлая/тёмная тема.

## Сборка
Во вкладке **Actions** на GitHub запустите «Build APK» (Run workflow). Через 5–10 минут внизу страницы запуска, в **Artifacts**, будут
`raspisanie-release` (оптимизированная, плавнее — ставьте её) и `raspisanie-debug` (запасная).

Все сборки подписаны одним и тем же ключом (`app/shared.keystore`), поэтому новую версию можно ставить поверх старой — кэш сохранится.
Ключ лежит в репозитории намеренно: приложение личное. Репозиторий лучше сделать приватным.

## Иконка
Сейчас иконка — просто белый фон. Замените `app/src/main/res/drawable/ic_launcher_foreground.xml` на свой рисунок
(или создайте иконку в Android Studio: New → Image Asset).
