# Расписание — приложение для Android

Показывает расписание колледжа на **сегодня** и **завтра** (и на любой другой день), в оформлении Material You.
Загружает свежие файлы расписания напрямую с сайта колледжа, и отображает их на главном экране.

## Что умеет
- Вкладки «Сегодня / Завтра» со свайпом, у каждой — отметка «есть / нет / ошибка».
- Современный дизайн: мерцающий скелет + этапы («Подключаюсь… → Ищу файл… → Готовлю картинку…»).
- Кэш на диске: при открытии расписание появляется мгновенно, свежая версия подгружается тихо.
- Потяните вниз — **файл скачивается заново с сервера РЖК**, картинка обновляется, если содержимое изменилось.
- Если расписания ещё нет — аккуратное пустое состояние и кнопка «Сообщить, когда выложат».
- Полноэкранный просмотр: щипок и двойной тап для увеличения, свайп между страницами.
- Уведомления: фоновая проверка каждые 15/30/60 минут (WorkManager).
- Динамические цвета из обоев (Android 12+), светлая/тёмная тема.
